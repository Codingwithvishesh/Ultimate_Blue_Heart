# 💙 Ultimate Slow-Reveal Cyberpunk Blue Heart Particle Engine

An ultra-smooth, high-performance particle engine in **Python (Pygame)**. It features an **organic radial wave reveal** where 5,000+ electric cyan particles blossom outward from the core in slow motion to form a glowing volumetric heart.

---

## ✨ Ultimate Reveal Physics
- **Center-to-Edge Radial Wave:** Center core se shockwave ki tarah particles gradually awaken hote hain.
- **Cubic Ease-Out Deceleration:** Particles center se nikal kar outer edge par smooth deceleration ke saath settle hote hain.
- **Micro-Fiber Fluffy Edges:** Gauss distribution mathematical curve gives natural fluffy glowing boundaries.
- **Synchronized Lub-Dub Heartbeat:** As the shape completes, it pulses in a dual-phase cardiac rhythm.
- **Pure Electric Cyan / Ice Blue Aesthetics:** Multi-tone blue palette against deep space-black backdrop.

---

## 🛠️ Quick Installation

1. **Install Pygame:**
   ```bash
   pip install -r requirements.txt
   ```
2. **Run Engine:**
   ```bash
   python main.py
   ```

## 🎮 Controls

| Key | Action |
| :--- | :--- |
| `SPACE` | Pause / Resume the reveal & heartbeat |
| `R` | Re-trigger slow reveal explosion from zero |
| `UP ARROW` | Reveal speed fast karein |
| `DOWN ARROW` | Reveal speed aur ultra-slow karein |
| `ESC / Close` | Exit |
